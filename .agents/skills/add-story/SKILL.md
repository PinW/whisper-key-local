name: add-story
description: "Write a user story. Use whenever working on the roadmap."
---

Write a user story and add it to @docs/roadmap/roadmap.md:
`- As a *[role]* I want **[feature]** so [benefit]`

- For the feature and benefit, be as specific as possible
- Append related GitHub issue/pr as (#number)
- Keep content concise without working notes
